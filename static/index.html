      IFP Repair Evaluation

      How to Use

      Use this application to document a repair evaluation and produce a professional PDF report.

      1. Enter Repair Information

      • Enter the Repair # manually.
      • Enter the date, customer, contact, customer PO, customer part number, make/model, serial number and technician.

      2. Document the Evaluation

      • Customer Request / Reported Problem — describe what the customer reported or requested.
      • Repair Evaluation / Findings — document inspection results, measurements, damage and other findings.

      3. Add Photos

      Use Add Photo to attach inspection photographs. Each photo can have its own description and can be rotated.

      4. Mark Up Photos

      Select a symbol from Add Symbol, then click on the photo where the symbol should be placed. Symbols are included in the PDF.

      5. Preview and Export

      Use Preview PDF to review the report. Use Print / Save PDF to download the finished report.

      6. Save Your Evaluation

      Save the evaluation to the server if you want to reopen or modify the report later. Use Open to reload it.

      Photo Markup Guide

      Place a Symbol

      Choose a symbol from Add Symbol, then click anywhere on the image. The symbol is placed at that location.

      Resize a Symbol

      Click an existing symbol to select it. Use the Size control to change its size. The selected symbol is highlighted in yellow.

      Move a Symbol

      Click and drag an existing symbol to move it.

      Remove a Symbol

      Select a symbol and press Delete, or use Clear Markups to remove all symbols from the photo.

      Zoom

      Use Open Photo / Zoom to enlarge the image while positioning markups. Zooming changes the view only; it does not change the underlying photograph.

      Available Symbols

      • Arrow Up / Right / Down / Left
      • Circle
      • Square
      • Rectangle
      • X
      • Check Mark

      Tip: Place the point of an arrow directly on the area you want the report reader to notice.
